# ВК «Авогадро» — офіційний сайт

Сайт волейбольного клубу з власною адмін-панеллю. Усе працює на **Vercel** (безкоштовний тариф Hobby):

| Частина | Технологія | Де |
|---|---|---|
| Сайт і адмінка | Next.js 16 (App Router) | Vercel |
| Дані (гравці, матчі, тексти, адміни) | Postgres | Neon (підключається через Vercel → Storage) |
| Фото гравців | Vercel Blob | Vercel → Storage |

- Сайт: `vk-avogadro.vercel.app`
- Адмінка: `vk-avogadro.vercel.app/admin`

## Що можна редагувати в адмінці

- **Гравці та штаб** — ім'я, номер, амплуа, фото (стискається автоматично).
- **Матчі** — суперник, дата й час (за Києвом), зал, рахунок за сетами після гри.
- **Налаштування сайту** — слоган, текст «Про клуб», телефон, email, адреса, соцмережі, місце залу на карті (міні-карта Google Maps у «Контактах»).
- **Адміністратори** — додати/забрати доступ, змінити свій пароль.

Зміни з'являються на сайті одразу після збереження.

## Налаштування на Vercel (один раз)

1. **Storage → Create → Neon (Postgres)**, регіон **Frankfurt (eu-central-1)**, план **Free** → Connect до проєкту `avohadro` (усі середовища). З'явиться змінна `DATABASE_URL`.
2. **Storage → Create → Blob**, тип доступу **Public** → Connect до проєкту. З'явиться `BLOB_READ_WRITE_TOKEN`.
3. **Settings → Environment Variables** — додати:
   - `SESSION_SECRET` — випадковий рядок ≥ 32 символів (напр. `openssl rand -base64 48`);
   - `ADMIN_EMAIL` — email першого адміністратора;
   - `ADMIN_PASSWORD` — його пароль (≥ 10 символів). Після першого входу змініть пароль в адмінці.
4. **Deployments → Redeploy**. Під час збірки автоматично створяться таблиці та перший адміністратор.

## Локальна розробка

```bash
npm install
cp .env.example .env.local   # заповнити DATABASE_URL, SESSION_SECRET, ADMIN_*
npm run db:migrate           # таблиці + перший адмін
npm run dev                  # http://localhost:3000
```

Без `BLOB_READ_WRITE_TOKEN` фото локально зберігаються в `public/uploads/` (лише для `npm run dev`).

## Команди

| Команда | Що робить |
|---|---|
| `npm run dev` | локальний сервер розробки |
| `npm run build` | міграції БД + продакшн-збірка (так само запускається на Vercel) |
| `npm run lint` / `npm run typecheck` | перевірки коду |
| `npm run db:generate` | нова міграція після зміни `src/db/schema.ts` |
| `npm run db:migrate` | застосувати міграції |

## Структура

```text
src/
├── app/
│   ├── page.tsx              головна сторінка (кешується, оновлюється після змін)
│   ├── admin/                адмін-панель
│   │   ├── actions.ts        серверні дії: збереження, видалення, вхід
│   │   ├── login/            сторінка входу
│   │   └── (panel)/          сторінки панелі (захищені)
│   └── styles/site.css       стилі сайту
├── components/               компоненти сайту та адмінки
├── db/schema.ts              схема БД (Drizzle ORM)
├── lib/                      авторизація, валідація, сховище фото, дані
└── proxy.ts                  захист /admin (Next.js 16 Proxy)
drizzle/                      SQL-міграції
scripts/migrate.mjs           міграції + початкові дані
```

## Безпека

- Паролі зберігаються як bcrypt-хеші; сесія — підписаний httpOnly-cookie (7 днів).
- Після 5 невдалих спроб входу — блокування на 15 хвилин (за email + IP).
- Зміна пароля завершує всі інші сесії цього адміністратора.
- Усі дані валідуються на сервері; посилання на соцмережі — лише `https://`.
- Адмінка закрита від пошукових систем (`noindex`, `robots.txt`).

## Ліміти безкоштовних тарифів

- **Vercel Hobby** — лише некомерційне використання (без продажу квитків, реклами, оплати за сайт). Донати дозволені.
- **Neon Free** — 1 ГБ даних, база «засинає» після 5 хв простою (сайт кешується, тож відвідувачі цього не помічають; перший вхід в адмінку після паузи може тривати ~1 с довше).
- **Vercel Blob (Hobby)** — 1 ГБ фото, 10 ГБ трафіку на місяць.
