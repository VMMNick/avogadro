# ВК «Авогадро» — офіційний сайт

Сайт волейбольного клубу з власною адмін-панеллю. Усе працює на **Vercel** (безкоштовний тариф Hobby):

| Частина | Технологія | Де |
|---|---|---|
| Сайт і адмінка | Next.js 16 (App Router) | Vercel |
| Дані (гравці, матчі, тексти, адміни) | Postgres | Neon (підключається через Vercel → Storage) |
| Фото гравців | Vercel Blob | Vercel → Storage |

- Сайт: `vk-avogadro.vercel.app`
- Адмінка: `vk-avogadro.vercel.app/admin`

## Що можна редагувати в адмінці

- **Гравці та штаб** — ім'я, номер, амплуа, фото (стискається автоматично).
- **Матчі** — суперник, дата й час (за Києвом), зал, турнір, тип (офіційний / товариський), рахунок за сетами й очки кожного сету, склад на гру та MVP матчу. Сезон (2025/26) визначається за датою автоматично.
- **Команди, Зали, Турніри** — довідники для швидкого заповнення матчів; у команд — логотипи й пошук; у турнірів — турнірна таблиця.
- **Налаштування сайту** — слоган, текст «Про клуб» (українською й англійською), телефон, email, адреса, карта, соцмережі.
- **Досягнення** — «полиця трофеїв» за сезонами (золото, срібло, бронза, кубок, нагорода).
- **Тренування** — розклад тренувань (день, час, зал) для блоку «Хочу до команди».
- **Заявки** — заявки з форми «Хочу до команди»: позначити опрацьованою або видалити.
- **Адміністратори** — додати/забрати доступ і вибрати роль (лише для ролі «адміністратор»).
- **Мій акаунт** — зміна свого пароля.

### Ролі

| Роль | Що може |
|---|---|
| **Адміністратор** | усе, зокрема налаштування сайту й керування доступом |
| **Редактор** | гравці, матчі, довідники, досягнення, тренування, заявки; без налаштувань сайту й адміністраторів |

Нові учасники, яких додали в панелі або які зареєструвалися за кодом запрошення, отримують роль **редактор**.
Підвищити до адміністратора можна на сторінці «Адміністратори».

На панелі «Огляд» з'являється нагадування, якщо зіграна гра досі без рахунку.

На сайті автоматично: фільтри матчів за сезоном і турніром, статистика (перемоги, сети, очки, найдовший сет, серія,
MVP сезону, особисті зустрічі), турнірна таблиця, кількість ігор і MVP на картках гравців,
окрема сторінка кожного матчу з картинкою для поширення, календар матчів (`/calendar.ics`, підписка в Google / Apple),
англійська версія (`/en`), розмітка для Google (клуб і матчі), карта сайту з усіма матчами.
На головній одразу завантажуються поточний і минулий сезони; старші — лише коли їх вибрати у фільтрі.

Також:

- **Сторінка календаря** `/calendar` — підписка й QR-код; сюди веде QR з афіш.
- **Афіша для друку** — на сторінці майбутнього матчу кнопка «Афіша для друку» (A4, з QR-кодом календаря).
  Також є посилання на сторінці редагування матчу в адмінці.
- **Застосунок на телефоні** — сайт можна встановити на головний екран (Android: кнопка «Встановити застосунок»
  внизу сайту або меню браузера; iPhone: «Поділитися → На початковий екран»). Без інтернету показується
  остання збережена версія сторінки з розкладом.

Зміни з'являються на сайті одразу після збереження.

## Налаштування на Vercel (один раз)

1. **Storage → Create → Neon (Postgres)**, регіон **Frankfurt (eu-central-1)**, план **Free** → Connect до проєкту `avohadro` (усі середовища). З'явиться змінна `DATABASE_URL`.
2. **Storage → Create → Blob**, тип доступу **Public** → Connect до проєкту. З'явиться `BLOB_READ_WRITE_TOKEN`.
3. **Settings → Environment Variables** — додати:
   - `SESSION_SECRET` — випадковий рядок ≥ 32 символів (напр. `openssl rand -base64 48`);
   - `ADMIN_EMAIL` — email першого адміністратора;
   - `ADMIN_PASSWORD` — його пароль (≥ 10 символів). Після першого входу змініть пароль в адмінці.
   - `ADMIN_INVITE_CODE` — необов'язково: код запрошення (≥ 8 символів) для реєстрації нових адмінів на `/admin/register`. Без нього реєстрацію вимкнено.
4. **Deployments → Redeploy**. Під час збірки автоматично створяться таблиці та перший адміністратор.

### Необов'язково

- **Статистика відвідувань і швидкості** — у проєкті відкрийте вкладки **Analytics** та **Speed Insights** і натисніть **Enable**. Код уже на сайті; адмінка в статистику не потрапляє. На Hobby: 50 000 подій Analytics на місяць і 10 000 подій Speed Insights за 30 днів.
- **Сповіщення про помилки (Sentry)** — зареєструйтеся на sentry.io (план Developer безкоштовний), створіть проєкт **Next.js**, скопіюйте **DSN** і додайте змінну `NEXT_PUBLIC_SENTRY_DSN`, потім Redeploy. Помилки надходитимуть на пошту. Cookies, паролі й тіла форм не надсилаються.
- **Власний домен** — **Settings → Domains → Add**, внесіть DNS-записи, які покаже Vercel, у реєстратора домену. Потім додайте змінну `NEXT_PUBLIC_SITE_URL=https://ваш-домен` (для посилань у календарі, картинок поширення й карти сайту) і Redeploy.
- **Сповіщення про нові заявки в Telegram** — створіть бота через @BotFather (отримаєте `TELEGRAM_BOT_TOKEN`), напишіть боту будь-що (або додайте його в групу тренерів), дізнайтеся id чату через `https://api.telegram.org/bot<токен>/getUpdates` і додайте змінні `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID`, потім Redeploy. Без них заявки просто з'являються в адмінці.
- **Блокувати деплой, якщо тести впали** — **Settings → Build and Deployment → Deployment Checks → Add Checks → GitHub** → виберіть перевірку `tests`. Після цього нова версія потрапляє на сайт лише коли автотести на GitHub пройшли.

## Локальна розробка

```bash
npm install
cp .env.example .env.local   # заповнити DATABASE_URL, SESSION_SECRET, ADMIN_*
npm run db:migrate           # таблиці + перший адмін
npm run dev                  # http://localhost:3000
```

Без `BLOB_READ_WRITE_TOKEN` фото локально зберігаються в `public/uploads/` (лише для `npm run dev`).

## Команди

| Команда | Що робить |
|---|---|
| `npm run dev` | локальний сервер розробки |
| `npm run build` | міграції БД + продакшн-збірка (так само запускається на Vercel) |
| `npm run lint` / `npm run typecheck` | перевірки коду |
| `npm run test:e2e` | автотести в браузері (див. нижче) |
| `npm run db:generate` | нова міграція після зміни `src/db/schema.ts` |
| `npm run db:migrate` | застосувати міграції |

## Автотести

Тести в `tests/e2e/` (Playwright) проходять сайтом і адмінкою як справжній користувач: вхід, гравці з фото,
матчі, сети, склад і MVP, довідники, пошук, логотипи, турнірна таблиця, сезони, статистика, календар, сторінки матчів,
англійська версія, телефонний вигляд. Окремий тест (`a11y.spec.ts`) перевіряє доступність за WCAG 2.1 AA (axe-core):
контраст, підписи полів, заголовки, назви кнопок, керування з клавіатури.

На GitHub вони запускаються автоматично на кожен push (`.github/workflows/tests.yml`) з тимчасовою базою.
Локально — лише з **окремою тестовою базою** (тести її очищають!):

```bash
# .env.local: DATABASE_URL тестової бази, SESSION_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD, ADMIN_INVITE_CODE,
# NEXT_PUBLIC_SITE_URL=http://localhost:3100
npm run build
npx playwright install chromium
npm run test:e2e
```

Щопонеділка GitHub перевіряє залежності (`.github/dependabot.yml`) і сам відкриває pull request з оновленнями —
тести запускаються на ньому автоматично. Якщо перевірка зелена, натисніть **Merge**; якщо червона — оновлення
краще не приймати й розібратися.

Сервер для тестів запускається з `E2E_TEST_MODE=1` — тільки тоді працює службова адреса очищення бази.
На Vercel вона вимкнена завжди.

## Безпека

- Паролі зберігаються як bcrypt-хеші; сесія — підписаний httpOnly-cookie (7 днів).
- Після 5 невдалих спроб входу — блокування на 15 хвилин (за email + IP).
- Зміна пароля завершує всі інші сесії цього адміністратора.
- Усі дані валідуються на сервері; посилання на соцмережі — лише `https://`.
- Адмінка закрита від пошукових систем (`noindex`, `robots.txt`).
- Форма «Хочу до команди»: прихована пастка для ботів, перевірка часу заповнення, не більше 3 заявок на годину з однієї адреси, обов'язкова згода на обробку даних.
- Заявки містять особисті дані (ім'я, телефон) — їх бачать лише учасники адмінки; опрацьовані заявки варто видаляти.

## Ліміти безкоштовних тарифів

- **Vercel Hobby** — лише некомерційне використання (без продажу квитків, реклами, оплати за сайт). Донати дозволені.
- **Neon Free** — 1 ГБ даних, база «засинає» після 5 хв простою (сайт кешується, тож відвідувачі цього не помічають; перший вхід в адмінку після паузи може тривати ~1 с довше).
- **Vercel Blob (Hobby)** — 1 ГБ фото, 10 ГБ трафіку на місяць.
- **Sentry Developer** — безкоштовно, 1 користувач, обмежена кількість помилок на місяць (для сайту клубу достатньо).

## Вхід в адмінку

На сайті кнопки входу немає. Адмінка відкривається лише за прямою адресою `/admin` (наприклад, https://vk-avogadro.vercel.app/admin). Там є вхід і, якщо задано `ADMIN_INVITE_CODE`, реєстрація за кодом запрошення.
